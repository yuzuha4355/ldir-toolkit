【受信者の手順 (Recipient's Steps)】

◆ パターンA: Windows → Linuxサーバ (SSH/WinSCP経由)

  [Windows側]
  1. Discordから以下をダウンロード:

  3. 証拠保存用の外部ストレージをマウント
     $ sudo mkdir -p /mnt/evidence
     $ sudo mount /dev/sdX1 /mnt/evidence  # sdX1は証拠保存先

     $ sudo ./ldir-collect.sh /mnt/evidence/ldir_output_$(date +%Y%m%d_%H%M%S)
  
  5. 実行完了後、外部ストレージを安全に取り外し
     $ sudo umount /mnt/evidence

【トラブルシューティング】

  Q1: "Permission denied" エラー
  A1: sudo権限で実行してください。
      $ sudo ./ldir-collect.sh /tmp/output

  Q2: "command not found: ldir-collect.sh"
  A2: 実行権限を付与してください。
      $ chmod +x ldir-collect.sh

  Q3: WinSCPで接続できない
  A3: SSHサービスが起動しているか確認してください。
      $ sudo systemctl status sshd

  Q4: 収集に時間がかかりすぎる
  A4: 大規模システムでは10分以上かかる場合があります。
      プロセスが動作していることを確認してください。
      $ ps aux | grep ldir-collect

  Q5: クラウド環境でメタデータが取得できない
  A5: IMDSv2トークン取得に失敗している可能性があります。
      ネットワーク設定とIAMロールを確認してください。

【収集データの検証】

  実行後、以下のファイルで証跡性を確認:
  
  /tmp/ldir_output/[hostname]_[timestamp]/
  ├─ metadata/
  │  ├─ manifest.txt          (収集ファイル一覧)
  │  └─ file_hashes.txt       (SHA256ハッシュ一覧)
  ├─ execution.log            (実行ログ - タイムスタンプ付き)
  └─ [各収集データディレクトリ]
